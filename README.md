# Projeto Neko Café
Projeto a ser apresentado como objeto avaliativo para a disciplina de Tecnologias Web no semestre 2026.1. 

### 1. Descrição do Projeto

Neko Café é um site para uma cafeteria temática que oferece cafés, doces e salgados em um ambiente voltado para a convivência com gatos disponíveis para adoção. O site tem como objetivo apresentar o estabelecimento, divulgar seu cardápio e promover a adoção responsável de animais, fornecendo informações sobre cada gato e formas de contato para os interessados.  
O projeto foi desenvolvido pelos alunos de Ciência da Computação do IFBA - Campus Paulo Afonso, Bruno Leandro Gama da Silva e Lorena Rachel Santos de Souza, como uma aplicação web front-end, com foco na experiência do usuário, organização das informações e design atrativo.


### 2. Funcionalidades

- Página inicial com apresentação da cafeteria.  
- Exibição do cardápio de cafés, doces e salgados.  
- Página dedicada aos gatos disponíveis para adoção.  
- Perfis dos gatos contendo:
    - Foto
    - Nome
    - Idade
    - Descrição
    - Personalidade
- Página "Sobre Nós".
- Navegação entre páginas através de menu.
- Layout responsivo para dispositivos móveis e desktops.
- Sistema de busca ou filtros visuais.


### 3. Motivação

O projeto foi inspirado no conceito dos cat cafés, estabelecimentos que unem a experiência gastronômica ao contato com gatos. Além de proporcionar um ambiente acolhedor aos clientes, esses espaços ajudam a divulgar animais que buscam um lar.  
A proposta do site é utilizar a tecnologia para apresentar a cafeteria e incentivar a adoção responsável, reunindo informações sobre os produtos e os animais em uma interface simples, organizada e agradável.


### 4. Objetivos

**Objetivo Geral**  
  Desenvolver uma interface web para divulgação de uma cafeteria temática voltada à adoção de gatos.

**Objetivos Específicos**  
Apresentar o cardápio da cafeteria.  
Divulgar os gatos disponíveis para adoção.  
Fornecer informações sobre o estabelecimento.  
Criar uma experiência de navegação intuitiva.  
Aplicar conceitos de desenvolvimento front-end e design responsivo.


### 5. Público-Alvo

Amantes de gatos.  
Pessoas interessadas em adoção de animais.  
Clientes da cafeteria.  
Jovens e adultos que buscam ambientes temáticos e acolhedores.


### 6. Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
